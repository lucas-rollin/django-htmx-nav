{% include "frontpage/components/_subsection_heading.html" with number="4.6" text="Orthogonal Add-ons: +hx-select (+HS) and +morph (+M)" %}

In the demo app, any variant can be combined with two orthogonal client-side axes:

+HS (hx-select-oob)

When enabled, the client uses hx-select-oob to pluck out secondary regions if the backend didn't supply them. Useful when migrating legacy views that still return full pages.

+M (Idiomorph)

Replaces HTMX's standard innerHTML replacement with Idiomorph's DOM morphing algorithm. Crucial for preserving input focus in search inputs and preventing scroll jumps.
